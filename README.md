# 🌟 《星光彈奏家 Starry Keys Master》 

> **2026 沉浸式互動音樂展覽 Web Rhythm Game**  
> 專為展覽場域打造的 30 秒快拍極限節奏遊戲，結合純程式 Web Audio 聲學合成與蒂芬妮青光彩視覺效果。

---

## 📌 專案緣由與動機 (Project Background & Motivation)

在許多大型設計展或互動裝置展覽中，傳統的節奏音樂遊戲常面臨以下挑戰：
1. **遊戲時間過長**：單曲動輒 3~5 分鐘，造成展場體驗排隊隊伍過長、輪替效率低下。
2. **操作選單複雜**：繁瑣的設定頁面與多按鍵配置，提高了非玩家型參觀者（如老少族群）的入門門檻。
3. **盲目刷分 Bugs**：部分體驗若缺乏防刷分機制，玩家只需「四鍵連按」即可過關，失去了音樂節奏與音符擊中的即時反饋樂趣。

**《星光彈奏家 Starry Keys Master》** 正是為了徹底解決上述問題而生！透過極簡化 **4 鍵直覺操作**、**30 秒快節奏體驗** 與 **即時 Web Audio 聲學合成**，讓任何參觀者都能在極短時間內享受流暢且極具成就感的打擊感感官盛宴。

---

## 🌟 核心特色 (Core Features)

* **⚡ 30 秒黃金體驗機制**：高密度的 30 秒快速模式，提高展覽場域玩家輪替率。
* **🎵 2026 流行樂團動態伴奏 Engine**：
  * 支援多首現代流行曲風（Funk Pop、Disco、K-Pop Dance、華語流行抒情、Pop Anthem）。
  * 背景自動播放輕量 Bass 律動與鼓點，並將和弦/和聲與玩家按下的鍵盤音符（D/F/J/K）進行**即時動態響應與合成**。
* **🎹 Web Audio 即時波形合成**：
  * 提供「🎹 鋼琴 (Piano)」與「💫 豎琴 (Harp)」兩種純程式合成音色，達到 0 延遲音訊反饋。
* **🛡️ 智慧防刷分機制 (Anti-Spam System)**：
  * 導入 **空按懲罰 (Miss Penalty)**：在沒有音符下落的區域亂按將強制判定 MISS 並扣分中斷 Combo。
  * **按鍵冷卻 (Overpress Limit)**：有效防止四鍵齊按的狂刷得分 Bug。
* **🔥 Dynamic Fever 2X Mode**：
  * 連擊（Combo）達 15 次以上將觸發狂熱 Mode，享有雙倍得分 multiplier 與霓虹視覺擴散波紋。
* **🎼 四大風格評審成績單**：
  * 體驗結束後由「莫札特」、「艾倫」、「雷哥」與「貓貓導師喵喵」針對 Perfect 數、Combo 與得分給予個人化專屬講評與稱號。

## 🛠️ 技術架構與使用技術 (Tech Stack)

* **前端介面**：HTML5, CSS3, Tailwind CSS (CDNJSDelivr)
* **視覺與粒子動畫**：HTML5 Canvas 2D API (音符下落、爆炸星芒粒子、衝擊波與音波視覺化)
* **聲音引擎**：Web Audio API (OscillatorNode, BiquadFilter, GainNode 即時諧波合成)
* **圖標庫**：FontAwesome 6.4.0
* **字體**：Google Fonts (Outfit & Noto Sans TC)

## 🚀 研發與開發歷程 (Development Roadmap)

- **Phase 1：品牌與視覺風格確立**
  - 定調夜空深藍色調、賽博蒂芬妮青/薄荷綠高對比流光視覺與一頁式展覽導覽架構。
- **Phase 2：Web Audio 與評審系統整合**
  - 導入純波形鋼琴與豎琴合成器，解決多媒體檔案載入延遲問題；設計四大性格評審結算彈窗。
- **Phase 3：流行曲庫與互動和聲升級**
  - 加入 2026 最新流行音樂曲目選單，升級伴奏引擎為「按鍵互動式流行和聲」，讓音樂聽感更和諧流暢。
- **Phase 4：防刷分與 Fever 狂熱機制**
  - 修正亂按刷分機制，新增打擊 Canvas 音頻波形顯示與熱血 Fever 2X 模式。

## 🎮 操作說明 (How to Play)

1. 開啟頁面後，點擊 **「開始體驗 (Start)」**。
2. 觀察音符從上方下降，當音符到達下方發光判定圈時，按下對應按鍵：
   * **軌道 1**：<kbd>D</kbd>
   * **軌道 2**：<kbd>F</kbd>
   * **軌道 3**：<kbd>J</kbd>
   * **軌道 4**：<kbd>K</kbd>
   *(行動裝置與觸控螢幕玩家可直接點擊下方虛擬按鍵)*
3. 避免空按區域以維持 Combo 連擊，挑戰更高的 SS 評級與星空講評！
